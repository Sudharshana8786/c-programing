 Day 1 C Programming

Subject: C Programming Day: 1 Topics: Introduction to C, Basic Syntax, Data Types, Input/Output and Operators.

This report contains the concepts learned and practical C programs completed during the first day of learning.

### Topics included

* Basic C program structure.

* Output statements and escape sequences.

* Data types – int, float and char.

* Input and output using scanf() and printf().

* ASCII values.

* Arithmetic, assignment and logical operators.

* Pre-increment, post-increment, pre-decrement and post-decrement.

* Basic C programming exercises.

### Learning Outcome

Understood the fundamentals of C programming and practiced writing simple programs using variables, input/output functions and operators.

### Next Learning Session

* Conditional statements (if/else).

* Looping statements.

* More practical C programming exercises.

Purpose: To build a strong foundation in C programming through theoretical learning and practical coding exercises.
